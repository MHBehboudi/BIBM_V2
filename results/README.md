# Results index

Everything the paper reports, where it lives, and what produces it. All files are regenerated by
`scripts/rebuild_results.sh` (CPU only) from the runs of record. The tables below read **only**
`raw/runs.csv`, `raw/anytime_curves.csv`, `exact_duration.json` and `gate_intervention.json`, so every number
can be checked without a GPU or the EEG data.

Status legend: **final** = all runs present; **PENDING** = runs launched 2026-09-17 still training (the file
is complete for what exists and marks the rest as pending).

## Raw data (`raw/`)

| file | one row per |
|---|---|
| `runs.csv` | run of record: arm, dataset, subject, seed, protocol, deadline window, loss weight, parameters, final-epoch accuracy / balanced accuracy / kappa / NLL / ECE, training accuracy, test-curve peak (diagnostic only), GPU, hours, record rule |
| `anytime_curves.csv` | (READER-family run, token): accuracy of the same model at every token boundary |
| `record_provenance.csv` | run of record: the development-harness directory it came from, its GPU, and why it was chosen (original / full-GPU re-run replacing a MIG run / MIG re-run pending / superseded) |

## Also here, not in the paper

`published_bite_tables.json` (BiTE's per-subject published numbers, parsed from their release),
`data_checksums.json`, and the model-free input probes behind negative results that the paper does not report
(`field_information_probe.json`, `common_mode_information.json`, `quotient_operator_probe.json`,
`reference_admittance_oracle.json`, `spectral_headroom_probe.json`).
